LSPosed-модуль для TikTok. Убирает рекламу, даёт скачивать что угодно в нужном качестве, включает функции, которые TikTok открывает не всем, и добавляет много мелочей: автопрокрутку везде, свой цвет, шрифт и AMOLED-тему, скрытие элементов, флаги стран, невидимку и автоогоньки.

> **Текущая версия: 4.5.0** · Проверено на TikTok **47.6.3**, **47.5.3**, **47.4.3**, **47.1.4** (Google Play и universal APK) · Android **16**. Статическая проверка также выполнена для TikTok global **47.9.3**.

## Что умеет

| Раздел | Примеры |
| --- | --- |
| **Лента** | без рекламы, скрыть LIVE и «Вероятные знакомые», только свежие и непросмотренные видео, свой фильтр по словам, авторам, странам, лайкам, просмотрам и длительности |
| **Просмотр** | автопрокрутка везде, точные даты и числа, свои скорости, 3×, частота экрана, перемотка на всех видео, качество по Wi-Fi и мобильной сети |
| **Интерфейс** | свой цвет и шрифт, AMOLED-тема, скрытие элементов, прозрачность, защита от выгорания, время у сообщений |
| **Комментарии** | кнопки перевода и автоперевод, копирование текста, флаги стран, репосты с комментарием |
| **Загрузки** | без водяного знака, выбор качества, карусели, стикеры, истории, аватары, запись LIVE, чистые ссылки |
| **Приватность** | невидимка, скрытие «печатает», «в сети», «прочитано», блокировка трекеров, случайный ID устройства |
| **Регион и огоньки** | страна SIM-карты, рекомендации на своём языке, автоогоньки с огоньками и стикерами |
| **Эксперименты** | скрытые функции TikTok, без обязательного входа, без лимита хештегов, функции камеры |

Полный список: [docs/FEATURES-RU.md](docs/FEATURES-RU.md). Бывшие экспериментальные функции включены по умолчанию.

## Установка

**Что нужно:** Android 8.1+, root и [LSPosed](https://github.com/JingMatrix/LSPosed) (libxposed 101–102 или старый LSPosed 1.9.x), TikTok из Google Play (`com.zhiliaoapp.musically`).

1. Скачайте APK из последнего [релиза](https://github.com/itswill00/TiktokPatchXposed/releases/latest) и установите.
2. В LSPosed включите модуль и отметьте TikTok.
3. Принудительно остановите TikTok и откройте снова.

**Настройки:** `TikTok → Профиль → ☰ → Настройки и конфиденциальность → TiktokPatchXposed` (первая строка). Экран переведён на 13 языков, включая арабский и китайский, и следует языку TikTok. Если настройка требует перезапуска, внизу появится кнопка **«Перезапустить»**. Обновление — новый APK поверх старого, настройки сохраняются.

## Сборка

```shell
./build.sh
```

Скрипт сам прогонит тесты, соберёт debug и release, загрузит новые APK в Telegram и покажет краткую сводку. Подробные параметры — в [docs/BUILDING.md](docs/BUILDING.md).

## Совместимость

Модуль цепляется только за читаемые имена TikTok. Запутанные места он находит сам при первом запуске новой версии по строкам и сигнатурам, затем запоминает результат. Поддерживаются сжатый код (беты, universal APK), переезд классов и TikTok, пропатченный через LSPatch. Каждая функция запускается отдельно: если одна не нашлась, остальные работают.

## Ограничения

- Иконку TikTok поменять нельзя.
- Часть элементов, нарисованных картинками, может остаться в цветах TikTok.
- Сервер TikTok может отклонить слишком длинный комментарий, несколько фото в комментарии или изменение хештегов.
- Регион аккаунта и IP-адрес модуль не меняет, поэтому результат не гарантирован.

Подробнее — [docs/TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).
